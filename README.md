# CX Offsite

- `invitation.html` — pre-event invitation
- `onsite.html` — live onsite team hub, scorecard and prize reveal

Open `onsite.html` in a modern browser. Visitor mode is read-only. Use **Organizer access** with the first-version code `CX2026` to edit teams and scores, unlock prizes, or launch the winner celebration.

Live data is saved in the browser on the onsite device.
